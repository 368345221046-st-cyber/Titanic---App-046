# 🐱🔔 ระบบทำนายผู้รอดชีวิตจากเรือไททานิค

แอปพลิเคชัน Streamlit สำหรับทำนายโอกาสรอดชีวิตของผู้โดยสารเรือไททานิค
โดยใช้โมเดล Support Vector Machine (SVM) ที่เทรนไว้ล่วงหน้า

พัฒนาโดย **นายอาทินันท์ วรรณารุณ**

## ไฟล์ในโปรเจกต์

| ไฟล์ | รายละเอียด |
|---|---|
| `app.py` | โค้ดหลักของแอป Streamlit |
| `requirements.txt` | รายการไลบรารีที่ต้องติดตั้ง |
| `titanic_svm.joblib` | โมเดล SVM ที่เทรนไว้แล้ว (ต้องอยู่โฟลเดอร์เดียวกับ app.py) |

## วิธีรันบนเครื่องตัวเอง

```bash
pip install -r requirements.txt
streamlit run app.py
```

## วิธี Deploy บน Streamlit Community Cloud

1. อัปโหลดทั้ง 3 ไฟล์ข้างต้น (`app.py`, `requirements.txt`, `titanic_svm.joblib`) ขึ้น GitHub repo เดียวกัน (วางไว้ที่ root ของ repo)
2. เข้า [share.streamlit.io](https://share.streamlit.io) แล้วเชื่อมต่อบัญชี GitHub
3. เลือก repo, branch และไฟล์ `app.py` เป็น main file
4. กด Deploy — ระบบจะติดตั้งไลบรารีจาก `requirements.txt` ให้อัตโนมัติ

## ⚠️ สิ่งที่ควรตรวจสอบก่อนใช้งานจริง

- ค่าตัวแปร `MODEL_ACCURACY` ใน `app.py` เป็นค่าตัวอย่างชั่วคราว กรุณาแก้ไขให้ตรงกับผลการประเมินโมเดลจริงของคุณ (เช่นจาก `accuracy_score` บนชุดข้อมูลทดสอบ)
- ไฟล์โมเดลที่ให้มาไม่ได้แนบตัวแปลงข้อมูล (scaler) มาด้วย ค่า mean/std ที่ใช้แปลงข้อมูลใน `app.py` คำนวณย้อนกลับจากค่าของโมเดลจนตรงกับสถิติของชุดข้อมูล Titanic มาตรฐาน หากโมเดลของคุณเทรนด้วยชุดข้อมูลอื่น ควรแทนที่ด้วยค่า mean/std จาก scaler ที่ใช้ตอนเทรนจริง
